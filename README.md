# RuangKampus - Aplikasi Web Peminjaman Fasilitas Kampus

Proyek web frontend untuk memudahkan mahasiswa dan pengurus organisasi mengecek ketersediaan ruangan serta mengajukan peminjaman secara daring.

## Struktur Proyek
- `index.html`: Berisi struktur markup semantik utama.
- `styles.css`: Lembar gaya modular dengan variabel kustom dan CSS Grid.
- `script.js`: Logika interaktif menu navigasi dan simulasi pengajuan.

## Cara Menjalankan
1. Unduh atau kloning repositori ini ke komputer Anda.
2. Buka berkas `index.html` menggunakan peramban web (browser) modern seperti Google Chrome atau Firefox.
3. (Opsional) Jalankan menggunakan Live Server di Visual Studio Code untuk pengalaman pengujian lokal.
